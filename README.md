# 🔖 Scoop Bucket for PerMark

[PerMark](https://github.com/EdelmarSchneider/permark) is a free, open-source Markdown app to read and review what your AI agents write, and steer the work through its documents. It opens any `.md` file as a clean page, with tables, diagrams and math, and keeps notes that save themselves.

## Install

```powershell
scoop bucket add permark https://github.com/EdelmarSchneider/scoop-permark
scoop install permark
```

## Update

```powershell
scoop update permark
```

## Coming from TrailMark?

TrailMark was renamed to PerMark. Your projects, settings and notes carry over. Switch with:

```powershell
scoop uninstall trailmark
scoop install permark
```
